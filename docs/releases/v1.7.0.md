# v1.7.0 — Off the deprecated DankIcon/DankFlickable shims

> **Language / Idioma:** English first, Português (Brasil) below.

Release date: 2026-11-26

## Highlights

- **No more deprecation errors in the shell log.** The widget used the `DankIcon` (6×) and `DankFlickable` (1×) shims, which DankMaterialShell 2.x / Dux Shell keeps only for compatibility: each instance logs `[Deprecation] … is deprecated and will be removed in a future release`. It now uses `DIcon` and `DFlickable` from `qs.DCommon.Widgets`, the same components the shims wrap, so rendering and behaviour are unchanged.

## Compatibility

- Requires DankMaterialShell / Dux Shell `>= 2.0.0` (was `>= 1.4.0`): `qs.DCommon.Widgets` does not exist in 1.x. Stay on v1.6.0 for a 1.x shell.
- No settings migration and no new translation keys.

## Validation

- `npm run check` passes (i18n parity for all 22 locales, parser tests, Markdown and QML validation).
- Checked against Dux Shell 2.1.2: `DankIcon` and `DankFlickable` there are thin wrappers (`DCommon.DIcon {}`, `DCommon.DFlickable {}`) that only add the deprecation log, so the replacement keeps the same API.
